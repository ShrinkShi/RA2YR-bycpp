The feature branch stores the two minimum first-slice game assets and the project-owned RA2/YR-inspired main-menu assets listed above. The complete 1GB+ RA2YR Compatibility Corpus remains in the separate `agent/ra2yr-corpus-lfs` worktree and is not copied or merged into this PR. `RA2YR_CORPUS_ROOT` is optional for corpus integration, import and Classic compatibility workflows; the Development Sandbox runs from its own `INI/` and `assets/` content root. The CnCNet/DTA repository remains an implementation and Editor HUD reference; its Tiberian Sun main-menu artwork is intentionally not used. House-color remap is project runtime logic over palette indices 16..31; no additional remap asset is copied.
