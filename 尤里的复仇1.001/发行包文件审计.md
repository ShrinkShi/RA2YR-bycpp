# 发行包文件审计

审计对象：维护者提供的 **RA2 1.006 + Yuri's Revenge 1.001，无过场动画，含官方地图增补、音乐包、Win10/11 兼容补丁** 的第三方整合发行包。

结论不是“看到老时间戳就算原版”。只有来源、内容位置、二进制标识和公开资料能够互相印证时，才提高可信度。

## C. 第三方兼容/发行包修改：不要当作 stock

### cnc-ddraw

```text
ddraw.dll
ddraw.ini
cnc-ddraw config.exe
Shaders/
```

确定是第三方 `cnc-ddraw`。

研究价值：高。

直接复用价值：低。我们做的是原生 SDL3 + D3D11 新 runtime，不需要再在新引擎上套 DirectDraw wrapper。

值得提炼的测试维度：

- fullscreen / borderless / resizable；
- maintain aspect ratio；
- nearest/bilinear/bicubic/lanczos 等缩放策略；
- VSync 与 input latency；
- renderer FPS 与 simulation tick 解耦；
- Alt-Tab / activate/deactivate；
- cursor scaling / confinement；
- old-game CPU affinity/freeze 问题只作为 legacy behavior 参考。

### `RA2MD.INI`

当前文件包含：

```text
AllowHiResModes=yes
VideoBackBuffer=no
AllowVRAMSidebar=no
ScreenWidth=1280
ScreenHeight=720
```

这证明发行包确实对显示/兼容配置做过处理。它是用户/发行包配置，不是纯净默认值。

### `game.fnt`

发行说明明确称额外加入“简体中文字体文件”；因此归类为发行包附加资源。

### `Sn_Changer.bat`

直接生成随机序列号并写入 `HKLM\SOFTWARE\Westwood\Yuri's Revenge`。属于联机/注册辅助脚本。

### `SetupReg.exe`

PE 资源字符串：

```text
Registry Setup - MYTH/DYNASTY
```

第三方注册/破解生态文件，不是原版数据格式研究对象。

### `YURI.EXE`

ASCII 字符串中直接存在：

```text
MYTH/DEViANCE
```

因此不把当前文件作为“Westwood 原始启动器”黄金样本。

## D. 可执行文件 / DLL：是否完全没用？

“EXE/DLL 不可读，所以全部忽略”这个假设不成立。

### 有研究价值但不进入内容 corpus

- `gamemd.exe`：最高价值。可做黑盒行为 oracle、异常输入对照、timing/load precedence 研究；不用于源码复制。
- `BINKW32.DLL`：说明原版 Bink 视频接口；等以后做到 movie playback 再研究，P0 不需要。
- `Blowfish.dll`：历史生态参考；但 encrypted MIX 已能独立解析，新引擎不应依赖它。
- `MPHMD.EXE`：可看到 UDP socket / multiplayer 相关字符串，适合后期网络历史研究；P0 无关。
- `DRVMGT.DLL`、`Cbnacw32.dll`：旧版驱动/复制保护或发行环境辅助，和核心 legacy asset reader 关联很低。

### 当前不值得投入逆向时间

- `RA2MD.EXE` 启动器；
- `Register.exe/Register.ini`；
- icon / launcher bitmap；
- patcher 数据和老 HTML UI；
- Taunts WAV（等音频阶段再进入 corpus）。

## E. UDP 宣传项的审计结论

标准 RA2/YR LAN fix 的常见实现是在游戏目录放 `wsock32.dll`，把原来的 IPX 联机适配到 UDP。

本样本：

```text
wsock32.dll: NOT FOUND
```

`gamemd.exe` 自己导入 Windows `WSOCK32.dll` 只能证明它使用 Winsock API，**不能证明第三方 UDP patch 已存在**。

因此发布者“加入 UDP 联机组件”的描述在当前样本上是 **未验证/不一致** 状态。
